# Tableau-ready source data

Place `heat_signal_tableau_data.csv` in this folder. It contains 17,830 aggregate records representing 264,750 NYC 311 HEAT/HOT WATER reports for calendar year 2024.

Use `SUM(Requests)` in Tableau. See [`../docs/DATA_DICTIONARY.md`](../docs/DATA_DICTIONARY.md) for fields and definitions.
